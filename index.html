The rationale sounds like design. The interface isn't.

Generative UI tools narrate their own design decisions - a three-column grid, accessible contrast, keyboard-navigable tabs. We built a benchmark to check whether any of it is actually in the code. Across 120 generated interfaces, over a quarter of stated design rationales were never implemented.

01

What user-facing design reasoning is

When you ask a tool for an interface, it usually explains itself first: what it will build, which principles it is honoring, what tradeoffs it made. That explanation is written for you, not for the compiler - nothing checks it against the output.

02

Why the gap matters

Design Theater is not a hallucination - it is a performance of design expertise. Fluent rationales invite less scrutiny, so the people now reviewing generated interfaces (product managers, engineers, first-time creators) may accept them precisely because they read as deliberate.

03

What the benchmark adds

Three metrics make three specific failure modes auditable: unimplemented rationales, missed UX obligations that were implied rather than stated, and homogenized design defaults dressed up as situated choices.

Design Theater: A Benchmark for Generative UI

Read paper GitHub Artifacts
Abstract

Generative user interface tools promise to democratize UI design by turning natural language descriptions into complete interfaces. Tools such as Claude Artifacts, ChatGPT and Replit generate user-facing design rationales that explain their layout, accessibility and design choices. However, it remains unclear whether these stated rationales are actually reflected in the interfaces they produce. We call this disconnect “Design Theater”: plausible and confident design rationales that have little relationship to the actual implementation.

To study this phenomenon, we introduce a benchmark and three metrics for measuring Design Theater. The benchmark includes 24 UI generation tasks spanning structural, styling and functional design requirements. Using it, we evaluate 120 interfaces created by generative UI tools. On average, over 25% of user-facing design rationales are not implemented in the generated interface, and the implementation failure increases to 34% for functional requirements. Tools recognize roughly half of the UX principles embedded in prompts (mean = 0.54), with four of five tools implementing 6% or fewer functional principles.

We also measure interface similarity across tools and find signs of design homogenization, with relatively narrow pairwise differences in overall visual appearance and layout organization and greater spread in color choices. We discuss what these findings mean for the design and evaluation of generative UI tools.

Method

24 tasks, 5 tools, three metrics.

Each of the five tools received the same 24 natural-language prompts, in its default configuration, with one fixed instruction: build the interface in plain HTML, CSS and JavaScript - no frameworks, no libraries, no web search. For every output we captured the code, the rendered interface, and the complete user-facing reasoning trace.

The tasks are written the way novices ask

Prompts never name a design principle. They describe users, contexts and constraints - a bilingual audience, a low-end phone, a stressed reader - so the principle is implied.

Tier 1 - Structural

What the interface contains

Information architecture: grouping related content, ordering sections, building navigation paths, routing distinct audiences, surfacing what is urgent. Eight tasks.

Tier 2 - Styling

How it looks

Visual communication: color, typography, spacing, hierarchy, contrast, emotional tone. Eight tasks, from straightforward branding to interfaces for constrained devices and readers under stress.

Tier 3 - Functional

How it behaves

Interaction: state, error prevention and recovery, user control, role switching, accessibility features. Eight tasks, from a four-step reservation flow to interactive systems serving large, diverse populations.

The three metrics

TFS

Thinking Fidelity Score

Did the tool build what it said it would?

We extract every concrete, checkable claim from the reasoning trace - "a three-column grid", "keyboard-navigable tabs". Vague claims are discarded. Two evaluators score each claim against the artifact: fully implemented (1.0), partially (0.5), not at all (0.0).

TFS = (1.0 · Nfull + 0.5 · Npartial) / Ntotal  

PAS

Principle Adherence Score

Did it honor the obligations nobody stated?

Two target UX principles are chosen per prompt before evaluation - structural tasks from information architecture, styling from WCAG, functional from Nielsen's heuristics. Each scores 1 or 0; PAS is their mean.

DHI

Design Homogeneity Index

Do five tools quietly build the same thing?

All 120 interfaces are rendered as 1200 x 1200 screenshots giving ten pairwise comparisons per prompt. Similarity is kept as three separate dimensions:

Visual

UIClip embeddings.

Color

CIELCh + Earth Mover's Distance.

Layout

OmniParser v2 + tree edit distance.

Results

No tool delivered on its own reasoning.

Cross-tool mean TFS was 0.75 - roughly one stated rationale in four did not fully appear in the interface. Four tools clustered between 0.74 and 0.87; Firebase Studio sat well below at 0.53.

Functional tasks were weakest across the board (0.66), but the shape of failure differs by tool: Claude held steady while Vercel v0 dropped sharply to 0.56 with a wide interval (0.36-0.77). A tool with moderate but stable fidelity is a different risk than one that is unpredictable.

Principle adherence collapses on interaction

Mean PAS ran from 0.29 (Firebase Studio) to 0.73 (ChatGPT). Tools handled structural and styling principles reasonably well and then fell off a cliff: four of five implemented 6% or fewer of the functional principles.

Design Homogeneity

Five tools, one house style.

Given the same prompt, the five tools produced interfaces that differed surprisingly little in overall appearance and layout. Color was the main dimension of divergence. Claude and Vercel v0 were consistently the closest pair on both visual and color distance.
