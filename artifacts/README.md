# Artifact Browser

Web app for viewing the generated interfaces  See the
[repository README](../README.md) for the benchmark and tools.

Interfaces are deployed using HTML, CSS, and JavaScript only, matching the
study constraint.

## Local development

```bash
npm install
npm run dev
```

Open http://localhost:3000.

Live at [design-theater.vercel.app](https://design-theater.vercel.app/).

## Tech stack

Next.js 16 · React 19 · TypeScript · Tailwind CSS
